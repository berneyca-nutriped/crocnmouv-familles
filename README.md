# Croc'n'Mouv Familles

Site des centres aérés [Croc'n'Mouv](https://crocnmouv.ch), adapté au téléphone et installable sur l'écran d'accueil.

- **Espace familles** : connexion avec le numéro de commande Squarespace, fiche de l'enfant (alimentation, allergies, santé, médicaments, droit à l'image), programme de la semaine, photos, recettes.
- **Espace équipe** : statut de chaque enfant par semaine (7 semaines d'été) et par groupe d'âge (6–12 ans), filtres, tableau, photos et vidéos à télécharger, publication de recettes, impression des listes.

## État actuel

Maquette sans serveur : toutes les données sont **fictives** et restent dans le navigateur. Aucune donnée réelle d'enfant ne doit être saisie à ce stade.

Pour la tester : ouvrir `index.html` dans un navigateur.
